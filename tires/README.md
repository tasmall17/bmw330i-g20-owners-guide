# Tires: G20 330i / 330i xDrive

Everything about picking, buying, and living with tires on this car, including how each choice
changes the way it **feels**.

## 60-second quick picker
1. **Read your sidewall.** Size (`225/45R18` ×4 = square, or `225/40R19` F + `255/35R19` R =
   staggered), and is it run-flat (`RFT`/`RSC`/`ZP`/`SSR`)? → [`oe-fitments.md`](oe-fitments.md)
2. **xDrive? Replace all four**, same model. → [`xdrive-tire-rules.md`](xdrive-tire-rules.md)
3. **Pick the category by climate** → [`categories-explained.md`](categories-explained.md)
4. **Decide on run-flats.** Most owners who switch to regular tires love it. → [`run-flat-vs-non-run-flat.md`](run-flat-vs-non-run-flat.md)
5. **Pick the tire** → [`tire-comparison.md`](tire-comparison.md)
6. **Buy & install** (rebates, fees, what to ask) → [`buying-and-installing.md`](buying-and-installing.md)

## The short answer for most owners (Oct 2026)
| Situation | Tire |
|---|---|
| One set, moderate snow, **18" square** | **Pirelli P Zero AS Plus 3** (quiet, lively, won Tire Rack's test on a 330i xDrive) · runner-up Michelin PSAS4 · real-snow pick **Vredestein Quatrac Pro+** |
| One set, moderate snow, **19" staggered** | **Continental DWS06 Plus** · runner-up Goodyear Eagle F1 All Season |
| Summer-only / warm climate | **Michelin Pilot Sport 4S** · runner-up Goodyear Eagle F1 Asymmetric 6 |
| Heavy snow | Summer/UHP set + **winter set on 18" wheels** (X-Ice Snow / Hakkapeliitta R5) |
