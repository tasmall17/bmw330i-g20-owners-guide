# vehicle/: what the car is

The reference shelf: what's in the car, how to identify exactly which version you have, and what
BMW still covers.

## Start here
- **[warranty-and-coverage.md](warranty-and-coverage.md)**: the most money-relevant doc in the repo.
  Emissions warranties cover valve cover gaskets, turbo, mechatronic and more to **7 yr / 70k** in 14
  states.
- **[decode-your-vin.md](decode-your-vin.md)**: find out if you have M Sport, run-flats, which wheels,
  which battery.
- **[specs-and-fluids.md](specs-and-fluids.md)**: oil spec, capacities, part numbers.
