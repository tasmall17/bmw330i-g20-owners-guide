# BMW G20 330i / 330i xDrive: the owner's knowledge base

Plain-English, sourced answers to the questions every G20 330i owner ends up asking: **What
maintenance actually matters? What should it cost at the dealer vs. an independent shop vs.
doing it yourself? Is this quote fair? Which tires should I buy?** Built around a 2022 330i
xDrive; most of it applies to every 2019–2024 G20 330i.

Every doc has a **"Last updated on"** stamp (top right) so you can judge freshness, and a
**Sources** section so you can check the work.

> ### ⚠️ Heads up (Oct 2026)
> - **Starter recalls with fire risk:** 26V056000 covers 330i/330i xDrive **built Nov 2020 – May 2024**
>   (specific starter); 25V636000 covers 2019–2021 330i (**park outside until fixed**). Free fix.
>   **Check your VIN at nhtsa.gov/recalls.** → [`recalls/`](recalls/README.md)
> - **Hidden warranty:** in 14 states (incl. CA, NY, NJ, PA, MA, MD, WA) BMW's emissions warranty covers
>   the **valve cover gasket, turbo, timing chain, transmission mechatronic, injectors and more for
>   7 years / 70,000 miles**. → [`vehicle/warranty-and-coverage.md`](vehicle/warranty-and-coverage.md)

## How the repo is organized
See [`.file-structure.md`](.file-structure.md) for the layout and the conventions every doc
follows (TL;DR/ELI5 → how much it matters → what forums say → cost & time → DIY verdict → sources).

## Keeping it current
Prices drift, recalls get issued, tire models get replaced. [`.update-the-repo-info/`](.update-the-repo-info/README.md)
is a step-by-step playbook (with a script) for refreshing the data, written so you can hand it to
an AI. Contributions welcome via PR; please follow the conventions.

## Using this with an AI
Point your assistant at `CLAUDE.md` first. It explains the read order and the rules. Raw data
for scripts lives in [`data/`](data/README.md).
