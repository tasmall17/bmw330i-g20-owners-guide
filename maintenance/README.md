# Maintenance: G20 330i / 330i xDrive

One doc per service item. Each opens with a one-paragraph **TL;DR / ELI5**, rates **how much it
actually matters**, summarizes **what the forums say**, and prices it three ways (**DIY →
Independent → Dealer**) with **time**.

> Full xDrive drivetrain service at an indie (trans + transfer case + both diffs): ~**$900–1,400**.

## The DIY starter kit (~$150–250 one time)
BimmerLink (or Carly) + a BMW-compatible OBD adapter (CBS resets, battery registration, rear
parking-brake service mode, transmission temperature) · torque wrench · Torx/E-Torx set · 14 mm
thin-wall spark-plug socket · low-profile jack + puck adapters + stands · brake pressure bleeder.
